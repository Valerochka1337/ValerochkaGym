# Выбор бесплатной модели OpenRouter

## Цель

Дать пользователю выбрать совместимую с обоими ИИ-сценариями бесплатную модель OpenRouter, а при
недоступности выбора быстро перейти к настройкам и сменить модель.

## Шаги

1. Получать актуальный каталог бесплатных моделей, которые одновременно принимают изображение и
   поддерживают структурированный JSON; сортировать их по практической пригодности.
2. Хранить выбранный ID в DataStore и использовать его для генерации упражнений и чтения InBody.
3. Показать выбор на экране настроек и дать действие «Открыть настройки» для ошибки недоступной
   модели в обоих сценариях ИИ.
4. Добавить тесты, обновить документацию и собрать release APK с debug/dev-подписью.
