# Автопрокрутка перестановки и единый текущий подход

## Цель

Сделать длинные списки упражнений переставляемыми до крайних позиций и оставить в активной
тренировке только одну развёрнутую карточку текущего подхода.

## Шаги

1. Вынести порог автопрокрутки 96dp для `ReorderableLazyListState` в общий внутренний компонент и
   подключить его в редактор программы и активную тренировку.
2. Вычислять текущий подход через `currentFocus()` по локальному порядку упражнений и передавать его
   id в карточки активной тренировки.
3. Добавить Compose-тест, который проверяет единственную кнопку завершения и переход фокуса после
   выполнения каждого подхода.
4. Запустить полный набор unit-тестов и debug-сборку.
