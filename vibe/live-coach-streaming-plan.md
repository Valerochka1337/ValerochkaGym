# Потоковый Live Coach

Источник задачи — переданный владельцем план; backend-контракт проверен по локальному
`ValerochkaGymBackend` (исходный контракт — коммит `eaac644`). Ветка —
`feat/live-coach-streaming` от актуальной `ValerochkaGym/main` (`207870f`).

1. Добавить отменяемый owner/epoch-bound POST `/v1/ai/coach-turn/stream` через OkHttp/Okio.
   SSE: UTF-8, LF/CRLF/CR, multiline data, heartbeat; 4 MiB поток / 256 KiB событие;
   60 секунд обмен, 180 секунд цикл. Запретить любые повторы POST.
2. Заменить gateway на Flow<TextDelta|Completed>, включая проверку модели. Выполнять
   инструменты только после completed с сохранением действующих проверок и лимитов.
3. Инкрементально извлекать только верхнеуровневую строку text. Для другого формата
   использовать CoachReply.decode исключительно после завершения ответа.
4. Хранить временный черновик в сервисе, привязать к запросу, тренировке, owner и epoch.
   Сбрасывать между обменами/перед инструментами/при ошибке и отмене. Сохранять один
   финальный ответ с тем же ID; дедуплицировать с Room при обновлении коллектора.
5. Сгладить только отображение: 32 мс, границы слов/графем, догон за 192 мс (≤200 мс).
   При возвращении в чат показывать накопленный текст сразу; поддержать отключённые
   анимации и TalkBack без озвучивания каждого фрагмента. Следовать за ответом только
   пока пользователь не читает историю.
6. Проверить парсер, gateway, агент, сервис, ViewModel и Compose рукописными фейками,
   виртуальным временем и semantics. Выполнить unit suite и assembleDebug без снимков.
7. Обновить контракт и правила чата. Версия один раз: 61/1.3.53 → 62/1.3.54.

Room и серверный API не меняются. Push, публикация и развёртывание не входят в работу.
До выпуска нужна отдельная авторизованная проверка доступности stream endpoint на
развёрнутом backend; наличие локальной реализации не подтверждает развёртывание.

Ориентиры (без новой зависимости и копирования реализации):
- [OkHttp SSE framing](https://github.com/square/okhttp/blob/master/okhttp-sse/src/main/kotlin/okhttp3/sse/internal/ServerSentEventReader.kt)
- [Vercel smoothStream](https://github.com/vercel/ai/blob/main/packages/ai/src/generate-text/smooth-stream.ts)
